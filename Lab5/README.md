# Lab 5 — Adaptive E-Commerce Item Detail Screen

Flutter (iOS) app that shows a **Product Preview** screen.

## Task
- Product Preview screen with a `Stack` cover image & bookmark badge
- Product title, star rating, price and category badges arranged with `Row` and `Wrap`
- Bottom sticky action bar with a full-width **Add to Cart** button via `Expanded`
- Zero `RenderFlex` overflow on small and large screens

## Run
```bash
flutter pub get
flutter run        # pick an iOS simulator
flutter test       # widget tests (small + large screen overflow checks)
```
